# Formulario-de-Inscricao
Projeto de um formulário fictíco

Ele será realizado de acordo com as orientações
do curso The Odin Project

Este formulário consiste no seguinte modelo:
- Uma foto grande na lateral esquerda, de cima a baixo
- Tal imagem possui uma logo
- A direita possui um texto e logo abaixo o formulário

- No formulário, temos 6 inputs, são eles:
- Primeiro nome
- segundo nome
- e-mail
- número de telefone
- senha e confirmar senha

- logo abaixo temos um botão de criar conta e em seguida
um texto perguntando se já possui uma conta com um link
para login.
